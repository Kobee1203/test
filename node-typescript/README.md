# Application Node.js + TypeScript

Petite application console en TypeScript avec tests unitaires sous Vitest.

## Prérequis

- Node.js (>= 18)
- npm ou pnpm

## Installation

```bash
cd node-typescript
pnpm install # ou npm install
```

## Exécution

Lancer l'application en console :
```bash
pnpm start # ou npm start
```

## Tests

Lancer les tests unitaires avec Vitest :
```bash
pnpm test # ou npm test
```
